# study-forge (학습지원 플러그인)

대학 강의 학습 지원 플러그인 (v0.9.0) — 구 study-assistant에서 개명 (2026-07-11)

대학 강의 학습지원을 위한 Cowork 플러그인. 예습부터 강의노트 작성, 복습, 시험대비까지 학습 전 과정을 자동화한다.

## 커맨드 전체 목록

### 학습관리 조교

| 커맨드 | 설명 |
|--------|------|
| `/ta` | 전체 과목 상태 자동 진단 → 지금 해야 할 작업 1~3개 제안 |

### 수업 전 — 예습

| 커맨드 | 설명 |
|--------|------|
| `/preview <과목> <주차>` | 강의교안 기반 대화형 예습 (주제별 소개 → 사전 지식 확인) |

### 수업 중 — 강의노트 작성

| 커맨드 | 설명 |
|--------|------|
| `/new-week <과목> <주차>` | 주차 전체 워크플로우 (변환 → 정리 → 노트 작성) |
| `/extract-video <과목> <주차>` | MP4에서 슬라이드 캡처 + 오디오 추출 |
| `/transcribe <과목> <주차>` | MP3 → 텍스트 스크립트 변환 |
| `/prepare-script <과목> <주차>` | 학습목록을 스크립트에 추가하여 구조화 |
| `/create-note <과목> <주차>` | 스크립트 + 교안 + 실습 → 강의노트 작성 |

### 수업 후 — 복습

| 커맨드 | 설명 |

## 과목 폴더 구조

마운트된 폴더를 과목 폴더로 자동 인식한다. 폴더명 형식은 자유.

```
과목명/
├── CLAUDE.md          # 학습지원 가이드
├── 강의교안/          # 주차별 PDF
├── 강의녹음/          # 주차별 MP3
├── 강의영상/          # 주차별 MP4 (선택)
├── 스크립트/          # 변환된 TXT (자동 생성)
├── 실습/              # 실습 PDF (선택)
└── 강의노트/          # 강의노트, 플래시카드, 시험정리 등
```

## 학습 사이클

```
뭐 하지?  →  /ta (조교가 현황 분석 후 다음 할 일 제안)
수업 전  →  /preview (교안 기반 예습)
수업 중  →  /new-week 또는 /extract-video + /transcribe + /create-note
수업 후  →  /review → /quiz → /flashcard
시험 전  →  /study-plan → /exam-summary → /mock-exam
수시     →  /solve (문제 풀이) · /search (키워드 검색) · /progress (현황)
```

## 설치

`.plugin` 파일을 Cowork에서 설치.

## 의존성

- `openai-whisper` + `ffmpeg` — 오디오/영상 처리
- `pdf2image` + `poppler-utils` — PDF → 이미지
- `pdfminer.six` — PDF 텍스트 추출

의존성은 각 스킬 실행 시 자동 설치.
