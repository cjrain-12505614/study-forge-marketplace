# /new-week 커맨드

사용자가 지정한 과목의 해당 주차 전체 강의노트 작성 워크플로우를 순차 실행한다.

## 인자 처리

- `$1` = 과목명 (예: 파이썬데이터분석, 머신러닝)
- `$2` = 주차 번호 (예: 3, 03)
- 인자가 없으면 마운트된 과목 목록을 보여주고 선택하게 한다

**iCloud 동기화 주의**: 워크스페이스 폴더가 iCloud Drive에 위치하여 VM과의 동기화에 지연이 있을 수 있습니다. 파일이 보이지 않으면 Mac Finder에서 해당 폴더를 열어 다운로드를 먼저 트리거하세요.

## 실행 순서

### Step 1: 파일 확인
1. 과목 폴더에서 해당 주차의 파일 현황을 확인한다
2. 강의영상 MP4가 있는지, MP3가 있는지, 강의교안 PDF가 있는지, 스크립트가 이미 있는지 체크
3. 현황을 사용자에게 보여준다

### Step 2: 영상 처리 및 전사 (whisper-mcp 비동기)
- **강의영상이 있는 경우** → `extract-video` 스킬 사용
  - 오디오 추출 (MP3가 이미 있으면 건너뜀)
  - whisper-mcp로 비동기 전사:
    - `transcribe_async`로 모든 MP3를 병렬 제출 (job_id 즉시 반환)
    - `check_job`으로 30-60초 간격 폴링하여 모든 작업 완료 대기
  - 스크립트 TXT의 `##(N)` 구역에 전사 텍스트 삽입
  - (선택) 슬라이드 프레임 캡처
- **MP3만 있는 경우** (영상 없음) → `transcribe` 스킬 사용
  - whisper-mcp로 비동기 전사:
    - `transcribe_async`로 모든 MP3를 병렬 제출
    - `check_job`으로 폴링하여 완료 대기
  - 스크립트 TXT의 `##(N)` 구역에 전사 텍스트 삽입
- **이미 스크립트 TXT에 전사 텍스트가 있으면** 이 단계를 건너뛴다

**주의**: 전사는 비동기 방식으로 동작합니다. 모든 MP3를 제출 후 폴링으로 완료를 기다리므로, 다음 Step 3 (prepare-script)은 전사가 모두 완료된 후에만 시작됩니다.

### Step 3: 학습목록 정리
- 사용자에게 학습목록 텍스트를 요청한다 (강의 사이트에서 복사-붙여넣기)
- `prepare-script` 스킬을 사용하여 #/## 구조로 변환하고 스크립트 상단에 삽입
- 이미 학습목록이 삽입된 스크립트라면 이 단계를 건너뛴다

### Step 4: 강의노트 작성
- `create-note` 스킬을 사용하여 강의노트를 작성한다
- 스크립트 + 강의교안 PDF + 실습 PDF를 종합하여 마크다운 노트 생성
- 강의노트/ 폴더에 `{00주차}-강의노트.md` 형식으로 저장

### Step 5: 완료 보고
- 생성된 파일 목록과 위치를 사용자에게 안내
- computer:// 링크로 강의노트 파일을 바로 열 수 있게 제공

## 건너뛰기 로직

각 단계에서 이미 결과물이 존재하면 사용자에게 알리고 건너뛸지 다시 실행할지 확인한다.

### 전사 완료 여부 판단

스크립트 TXT의 `<강의녹음 스크립트>` 구역에서 `##(N)` 아래에 텍스트가 있으면 전사 완료로 판단한다. `##(N)` 바로 아래가 비어있거나 다음 `##` 태그가 오면 미완료로 판단한다.
