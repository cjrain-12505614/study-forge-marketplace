# /transcribe 커맨드

지정한 과목·주차의 MP3 파일을 Whisper로 텍스트 변환하여 스크립트/ 폴더에 저장한다.

## 인자 처리

- `$1` = 과목명 (선택, 없으면 과목 목록에서 선택)
- `$2` = 주차 번호 (선택, 없으면 변환되지 않은 MP3 목록 제시)

## 실행

1. `transcribe` 스킬의 워크플로우를 실행한다
2. 과목 폴더의 강의녹음/ 디렉토리에서 MP3 파일을 탐색
3. Whisper medium 모델로 한국어 변환
4. 스크립트/ 폴더에 `{00주차}-스크립트.txt` 형식으로 저장
5. 변환 결과를 사용자에게 안내

## 다음 단계 안내

변환 완료 후 `/prepare-script`로 학습목록을 추가하거나, `/new-week`으로 전체 워크플로우를 실행할 수 있음을 안내한다.
