# /mock-exam 커맨드

시험 범위 전체를 대상으로 실전 모의시험을 생성하고, 일괄 채점 후 취약 단원을 분석한다.

## 인자

- `$1` = 과목명 (선택)
- `$2` = 주차 범위 (예: 1-7) (선택)

## 실행

1. `mock-exam` 스킬의 워크플로우를 실행
2. 범위 내 강의노트 기반 25문제 생성 (전체 한 번에 출제)
3. 사용자 풀이 → 답안 수집
4. 일괄 채점 + 주제별 정답률 분석
5. 취약 단원 해설 + 복습 추천
6. (선택) 오답노트 파일 저장
