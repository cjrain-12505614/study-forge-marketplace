# study-forge (학습지원 플러그인)

대학 강의 학습 지원 플러그인 (v1.1.2) — 구 study-assistant에서 개명 (2026-07-11)

> **v1.1.2 — 미완료 주차의 표준 절차를 「같이 보며 동행 모니터링」으로 못박음.** v1.1.1의 「자막은 잠금과 무관하다」는 **과잉 주장**이었다 — 여는 것 자체가 막히면 자막도 못 받는다. 문제해결프로그래밍입문 2주차에서 강의실홈의 `입력`을 직접 클릭했더니 「동일주차내 '2주차내 (들어가기)' 아이템이 미완료입니다」로 **열리지도 않았다**. **잠금 강도는 과목 성질이 아니라 주차의 완료 상태가 정한다** — 완료된 주차는 `›` 순회로 항목당 5~10초에 수확되고(딥러닝 10개 ≈ 1분), 미완료 주차는 첫 항목부터 순서대로만 열린다. → ⛔ **잠금을 우회하지 말 것.** 미완료 주차는 사용자와 **함께 재생하며 자동 전환을 따라가고**, 항목마다 자막을 수확한다. 슬라이드형(`학습개요` 등)은 열람만으로 완료되어 다음을 연다. 수강은 사용자 본인의 행위이므로 **함께 볼 때만** 쓰는 절차임을 명시했다. `confirm-toc` v0.7.2.
>
> **v1.1.1 — 퀴즈 유형 분기 + 순차 잠금 정정.** 빅데이터분석실무 2주차 실전에서 v1.1.0의 서술 2건이 반증됐다. ① **「거짓 진술 문항에만 해설」은 과목 공통이 아니라 O/X형 한정**이다 — 번호 배지형 객관식(4지선다)은 **전 문항에 해설**이 붙는다(빅데이터 4문항 전수). 번호 배지형에서 빈 해설은 정상이 아니라 추출 실패다. ② **「빅데이터는 모듈 안에서 자유 점프가 된다」는 틀렸다** — 그때 그 항목들이 이미 완료였을 뿐이고, 미완료 항목에서는 `›` 화살표도 막힌다(「현재 콘텐츠 아이템의 학습 완료가 되지 않아…」). **과목 성질이 아니라 완료 상태의 문제다.** 이 잠금은 `학습평가`·`학습정리` 채록을 직접 막으므로 선행 영상을 실제로 완료해야 도달한다 — 단 **자막은 로드만으로 받아지므로 잠금과 무관**하다. ③ 선택지 인덱스 매핑에 번호 배지형(`opts[n*k+(i-1)]`, `.item-select-option-no`)을 추가했다 — 버튼 매핑(`btns[2k]`)은 두 유형이 같다. `confirm-toc` v0.7.1.
>
> **v1.1.0 — 강의실 공식 자막을 본문 정본으로 승격.** 파이프라인 순서가 뒤집혔다.
> 플레이어의 `video.textTracks`에 **사람이 만든 한국어 자막**이 타임스탬프째로 실려 있고, 항목을 **로드**하면 전량 로드된다(재생 완주 불필요 — 딥러닝 2주차 10개를 약 1분에 수집). 같은 음원 대조에서 자막의 우위가 확인됐다 — `이산값` 자막 4/4 정확 vs 다글로 1건 오인식, 규범 표기 일관(`경사 하강법` 40:0 · `손실 함수` 41:0 · `최솟값` 28:0), whisper는 「금방 할 수 없고」를 「할 수 있고」로 **의미 반전**시켰다. → **1순위 자막(무료) · 2순위 다글로 · 3순위 whisper**로 계층을 재정의하고, `transcribe`·`extract-video`를 폴백으로 강등했다. 자막 경로에서는 **전문용어 후처리가 불필요**하다(용어집의 `에폭`은 오히려 틀렸다 — 강의·자막 모두 `에포크`). 수집물은 **localStorage 자동 백업 + blob 다운로드**로 반출한다(227KB 실측, 에이전트 맥락 비경유). 문단 나눔은 cue 간격이 전부 0.30초로 균일해 시간 기반이 불가능하므로 **문장 경계**로 끊는다. 부수 수정 — 자동 채록기 임계값 400자가 `학습개요`(230자)를 놓치던 것, `create-note` 착수 조건이 「전사 완료」라 자막 스크립트를 미충족 판정하던 것, `transcribe.md`의 죽은 「폴백」 절 참조. `confirm-toc` v1.0.0.
>
> **v1.0.0 — 5과목 1·2주차를 실제로 완주하며 절차가 안정화되어 1.0으로 올린다.**
> 딥러닝 2주차 `학습평가`·`학습정리` 자동 채록에서 얻은 것을 반영. **퀴즈는 표준 폼이 아니라 `maui` 커스텀 컴포넌트**(선택지 `div.component-data-field`, 버튼 `span.maui-border-button`)이고, ⚠️ **버튼이 문항당 2개**(`정답확인`+`다시풀기`)라 텍스트 필터링하면 이미 채점된 문항을 다시 눌러 헛돈다 — **위치 인덱스** `btns[2k]`로 매핑한다. `el.click()` 단독으로는 반응하지 않아 `pointerdown→mousedown→pointerup→mouseup→click` 디스패치가 필요하고, **async 일괄 처리는 실패**해 문항마다 동기 분할 호출해야 한다. 정답 정규식에 부정 전방탐색을 넣어 버튼 텍스트 `정답확인`을 정답으로 읽는 **오매치 버그**를 막고(기존 절단 버그와 반대 방향), 정답·해설을 **독립 정규식으로 분리**해 해설 없는 참 진술 문항에서 정답까지 잃던 결함을 고쳤다. **거짓 진술 문항에만 해설이 붙는 것이 과목 공통 패턴**임을 확정 — 빈 해설은 추출 실패가 아니다. 상위 항목 수동 이동 수단(**플레이어 우하단 `‹ ›` 화살표**)과 **상호작용 페이지는 자동 전환되지 않는다**는 사실을 신설. 전환 로거 dedup 키에 본문 글자수를 넣어 **채점 전/후를 각각 보존**하고, 콘텐츠 추출을 `.toc-row` 기준으로 통일했다(「가장 긴 텍스트」 휴리스틱은 바깥 강의실 문서를 잡는다). `confirm-toc` v0.6.0.
>
> v0.13.0 — 2주차 5과목 실측 반영. **강의시간 노출 3분류 폐기**(전 과목 인라인 노출 확인), **상위 항목 강의시간 = 하위 MP3 각항 내림 합**(반올림·합계후내림은 5과목 전부 해 없음), **재생 없이 그룹 경계를 확정하는 산술 절차**(`confirm-toc` 0-B단계 · 순서보존 연속 블록 전수 탐색 · 5과목 유일해), **상위 항목 진입 시 하위 목차명 전부 노출**(이름 채록에 하위 전량 재생 불필요), 전환 로거(`__scuRead`/`__scuLog`), 인트로 길이는 고정값 아님(랜덤 클립 실측 13.11초 — `currentSrc`로만 판별), 좌표 클릭 자동재생 사고 재발 방지, 수치 출처 표기 의무화. `confirm-toc` v0.5.0.

## 과목 폴더 구조

마운트된 폴더를 과목 폴더로 자동 인식한다. 폴더명 형식은 자유.

```
과목명/
├── CLAUDE.md          # 학습지원 가이드
├── 강의교안/          # 주차별 PDF
├── 강의녹음/          # 주차별 MP3
├── 강의영상/          # 주차별 MP4 (선택)
├── 스크립트/          # 변환된 TXT (자동 생성)
├── 실습/              # 실습 PDF (선택)
└── 강의노트/          # 강의노트, 플래시카드, 시험정리 등
```

## 학습 사이클

```
뭐 하지?  →  /ta (조교가 현황 분석 후 다음 할 일 제안)
수업 전  →  /preview (교안 기반 예습)
수업 중  →  /new-week 또는 /collect-week + /transcribe + /confirm-toc + /create-note
수업 후  →  /review → /quiz → /flashcard
시험 전  →  /study-plan → /exam-summary → /mock-exam
수시     →  /solve (문제 풀이) · /search (키워드 검색) · /progress (현황)
```

## 설치

`.plugin` 파일을 Cowork에서 설치.

## 의존성

- 다글로(daglo) MCP + `ffmpeg` — 전사(클라우드·유료) 및 오디오/영상 처리(로컬)
- `poppler` (`pdftoppm`) — PDF → 이미지 (맥 `brew install poppler`)
- `pdfminer.six` — PDF 텍스트 추출
- `playwright` + Chromium — 다이어그램 PNG 렌더링 (맥은 시스템 한글 폰트로 충분)

의존성은 각 스킬 실행 시 자동 설치.
