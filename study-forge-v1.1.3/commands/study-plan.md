# /study-plan 커맨드

시험 일정을 기준으로 일별 복습 계획을 생성한다.

## 인자

- `$1` = 과목명 (선택)
- `$2` = 시험 일자 (예: 4/20) (선택)

## 실행

1. `study-plan` 스킬의 워크플로우를 실행
2. 시험 범위·취약 단원 파악
3. 간격 반복 + 취약 우선 원칙으로 일별 스케줄 생성
4. (선택) Google Calendar에 학습 블록 등록
5. 마크다운 계획표 저장 + 링크 제공
