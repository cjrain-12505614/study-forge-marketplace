# /solve 커맨드

문제를 텍스트로 입력하거나 이미지로 첨부하면, 문제를 정형화하고 정답과 해설을 제공한다.

## 사용 방법

- `/solve` + 문제 텍스트 붙여넣기
- `/solve` + 문제 이미지 첨부
- `/solve` + 여러 문제 한 번에 붙여넣기

## 실행

1. `solve-question` 스킬의 워크플로우를 실행한다
2. 텍스트/이미지에서 문제 내용을 파악
3. 문제를 정형 포맷으로 재정의 (문제 본문 + 보기)
4. 정답 도출 + 해설 작성
5. 관련 강의노트가 있으면 주차 연결

## 과목 지정

과목을 지정하면 해당 과목의 강의노트를 참조하여 해설의 근거를 강의 내용에서 찾는다.
과목 미지정 시 일반 지식으로 풀이한다.
