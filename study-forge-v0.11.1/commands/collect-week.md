# /collect-week 커맨드

포털에서 지정한 과목·주차의 학습 자료를 받아 `강의교안/`·`강의녹음/`에 배치한다.

## 인자 처리

- `$1` = 과목명 (선택, 없으면 과목 목록에서 선택)
- `$2` = 주차 번호 (선택, 없으면 현재 주차를 학사일정에서 추정해 제시하고 확인받는다)

## 실행

1. `collect-week` 스킬의 워크플로우를 실행한다
2. **사전 확인** — Chrome 자동 다운로드 예외(`home.iscu.ac.kr`)와 다운로드 폴더 경로
3. 과목 폴더 `CLAUDE.md`에서 강좌코드를 읽고 교안자료실에 폼 POST로 진입
4. ⚠️ **저작권 고지 동의 승인** — 모달 `확인`을 대신 눌러도 되는지 세션당 1회 확인
5. 해당 주차 교안 PDF 다운로드 → `강의교안/`
6. 해당 주차 MP3 → **`MP3 ZIP 전체 다운로드`** 1회 → 압축 해제 → `강의녹음/`
7. `ffprobe`로 MP3별 재생시간 기록 (다음 단계 `confirm-toc`의 매칭 근거)
8. 수집 결과·참여도 집계 현황 보고

## 주의

- ⚠️ **교안 다운로드는 참여도 점수에 집계**된다(과목별 9회 기준). **해당 주차분만** 받고 학기 전체를 몰아 받지 않는다
- MP3는 해당 주차 콘텐츠가 공개된 뒤에만 제공된다 — **아이콘 유무로 판단하지 말고** 목록을 열어 확인
- Chrome 예외가 없으면 **두 번째 파일부터 조용히 사라진다** — 에러도 기록도 남지 않음
- 포털 세션이 만료되면 SSO 로그인이 필요하다 — **대신 로그인할 수 없으므로** 사용자에게 요청
- 다운로드 폴더는 Chrome 설정값을 읽는다 (`~/Downloads` 가정 금지)
