# /new-week 커맨드

사용자가 지정한 과목의 해당 주차 전체 강의노트 작성 워크플로우를 순차 실행한다.

## 인자 처리

- `$1` = 과목명 (예: 파이썬데이터분석, 머신러닝)
- `$2` = 주차 번호 (예: 3, 03)
- 인자가 없으면 마운트된 과목 목록을 보여주고 선택하게 한다

**iCloud 동기화 주의**: 워크스페이스 폴더가 iCloud Drive에 위치하여 VM과의 동기화에 지연이 있을 수 있습니다. 파일이 보이지 않으면 Mac Finder에서 해당 폴더를 열어 다운로드를 먼저 트리거하세요.

## 파이프라인

```
collect-week → transcribe / extract-video → confirm-toc → prepare-script → create-note
   자료 수집        전사(⚠️유료)              목차 확정      스크립트 구조화     노트 작성
```

각 단계는 **이미 결과물이 있으면 건너뛴다.** 재실행은 시간·크레딧 낭비다.

## 시작 전 필수

1. 워크스페이스 `CLAUDE.md`와 **과목 폴더 `CLAUDE.md`**를 읽는다
2. **기존 주차 산출물을 열어 형식을 확인**한다
3. 확인할 수 없는 값은 **비워 두고 채울 방법을 안내**한다 — 그럴듯한 추정값 금지

## 실행 순서

### Step 1: 파일 확인 및 수집

1. 과목 폴더에서 해당 주차의 파일 현황을 확인한다
2. 강의영상 MP4·MP3·강의교안 PDF·스크립트가 이미 있는지 체크
3. **자료가 없으면 `collect-week` 스킬로 포털에서 수집한다**
   - ⚠️ 교안 다운로드는 **참여도에 집계**된다 — 해당 주차분만 받는다
   - ⚠️ Chrome 자동 다운로드 예외가 없으면 **두 번째 파일부터 조용히 사라진다**
   - MP3는 해당 주차가 열려야 제공된다 — 없으면 그 사실을 알리고 진행 가능한 범위까지만 처리
4. MP3별 재생시간을 `ffprobe`로 기록해 둔다 (Step 3의 목차 매칭 근거)
5. 현황을 사용자에게 보여준다

### Step 2: 영상 처리 및 전사 (다글로 MCP)

> ⚠️ **다글로 전사는 유료 크레딧을 소모하고 파일을 클라우드로 업로드한다.** 이 Step에서 전사를 시작하기 전에 **반드시 대상 파일 목록·개수·옵션을 제시하고 사용자 승인을 받는다.** 승인 없이 `dry_run=False`로 호출하지 않는다.

- **강의영상이 있는 경우** → `extract-video` 스킬 사용
  - 오디오 추출 (MP3가 이미 있으면 건너뜀) — 로컬·무료
  - 다글로 업로드(무료) → **승인 게이트** → 전사:
    - `upload_file`로 모든 MP3 업로드하여 `fileMetaId` 수집
    - 사용자 승인 후 `start_transcription(file_meta_ids[...], dry_run=False)` 일괄 시작
    - `get_file_status` 폴링 → `get_transcript(with_time=False)`로 평문 회수
  - 스크립트 TXT의 `##(N)` 구역에 전사 텍스트 삽입
  - (선택) 슬라이드 프레임 캡처 — 로컬·무료이므로 전사 대기 중 병행 가능
- **MP3만 있는 경우** (영상 없음) → `transcribe` 스킬 사용
  - 위와 동일한 업로드 → 승인 → 전사 → 회수 흐름
  - 스크립트 TXT의 `##(N)` 구역에 전사 텍스트 삽입
- **이미 스크립트 TXT에 전사 텍스트가 있으면** 이 단계를 건너뛴다 (불필요한 과금 방지)

**주의**: 전사는 서버에서 비동기로 처리된다. 업로드를 모두 마친 뒤 승인 게이트를 **1회만** 거치고 일괄 시작하며, 폴링으로 완료를 기다린다. `file_meta_ids`는 **요청당 5개 상한**이고 `topic`은 **서버 enum(`IT`)** 이다. 다음 Step은 전사가 모두 완료된 후에만 시작한다. 폴링이 타임아웃돼도 서버 전사는 계속되므로 `fileMetaId`를 보존해 두면 나중에 회수할 수 있다.

**사용자가 전사를 거부한 경우**: 영상이 있으면 프레임 캡처만 수행하고, 전사가 필요한 이후 Step은 중단한 뒤 사용자에게 상황을 알린다.

### Step 3: 학습목차 확정 (`confirm-toc`)

- 상위 목차(`#`)는 강의실 주차 목록에서 바로 읽는다 — 재생 불필요
- 하위 목차(`##(N)`)가 수강해야만 보이는 구조라면 `confirm-toc` 스킬로 진행한다
  - ⛔ **목차를 알아내려고 강의를 재생하지 말 것** — 진도·출석이 오르며 학교가 대리출석을 금지한다
  - ⛔ **전사 내용으로 목차명을 추정해 지어내지 말 것** — 그럴듯하지만 전량 틀린다
  - 확정 근거는 **영상 길이 = MP3 길이(초 단위 일치)**
- **`학습평가`·`학습정리`는 MP3가 없어 여기서 채록하지 않으면 복원 경로가 없다**
- 사용자가 이미 목차를 붙여넣어 줬으면 이 단계를 건너뛴다

### Step 4: 스크립트 정리 (`prepare-script`)

- 확정된 목차를 `#`/`##(N)`/`---` 구조로 변환하고 스크립트 상단에 삽입
- 이미 학습목차가 삽입된 스크립트라면 이 단계를 건너뛴다
- ⚠️ 목차와 본문에 같은 문자열이 있으므로 **인덱스 기반 편집 금지** — 소스에서 재생성한다

### Step 5: 강의노트 작성
- `create-note` 스킬을 사용하여 강의노트를 작성한다 (0~10단계 전부 수행, 플랜 모드 필수)
- 스크립트 + 강의교안 PDF + 실습 PDF + 영상 프레임을 종합하여 마크다운 노트 생성
- `학습평가`·`학습정리`는 **제목만 남기지 말고 내용까지 채운다** (Step 3 채록본 사용)
- 강의노트/ 폴더에 `{00주차}-강의노트.md` 형식으로 저장 (NFD 경로 검증)

### Step 6: 완료 보고
- 생성된 파일 목록과 위치를 사용자에게 안내
- computer:// 링크로 강의노트 파일을 바로 열 수 있게 제공

## 건너뛰기 로직

각 단계에서 이미 결과물이 존재하면 사용자에게 알리고 건너뛸지 다시 실행할지 확인한다.

### 전사 완료 여부 판단

스크립트 TXT의 `<강의녹음 스크립트>` 구역에서 `##(N)` 아래에 텍스트가 있으면 전사 완료로 판단한다. `##(N)` 바로 아래가 비어있거나 다음 `##` 태그가 오면 미완료로 판단한다.
