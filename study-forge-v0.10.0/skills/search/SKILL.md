# 전체 노트 키워드 검색 스킬

마운트된 전체 과목의 강의노트에서 키워드를 검색하여 관련 내용을 컨텍스트와 함께 보여준다.

## 1단계: 키워드 파악

사용자의 검색 키워드를 파악한다.
- 단일 키워드: "정규화"
- 복수 키워드: "정규화 과적합"
- 질문형: "선형 회귀를 어디서 배웠지?"에서 "선형 회귀" 추출

## 2단계: 전체 노트 검색

모든 과목 폴더의 강의노트/ 디렉토리에서 키워드를 검색한다.

Grep 도구를 사용:
```
Grep(
    pattern='키워드',
    path='/sessions/{session_id}/mnt/',
    glob='**/강의노트/*.md',
    output_mode='content',
    context=3  # 전후 3줄 컨텍스트
)
```

## 3단계: 결과 정리

### 결과 포맷

```markdown
## "정규화" 검색 결과 (3건)

### 머신러닝 — 04주차 강의노트
> ### 정규화 (Regularization)
> - 모델의 복잡도를 제한하여 과적합을 방지하는 기법
> - L1 정규화(Lasso): 가중치를 0으로 만들어 특성 선택 효과
> - L2 정규화(Ridge): 가중치를 작게 만들어 모델 단순화

### 파이썬데이터분석 — 06주차 강의노트
> ### 데이터 정규화
> - Min-Max 정규화: 값을 0~1 범위로 변환
> - Z-score 정규화: 평균 0, 표준편차 1로 변환

### 빅데이터기초수학 — 03주차 강의노트
> - 벡터의 정규화(normalization): 크기를 1로 만드는 연산
```

### 동음이의어·다의어 처리
- 같은 키워드가 다른 맥락(과목)에서 다른 의미로 사용될 수 있음
- 각 결과에 과목명과 주변 컨텍스트를 포함하여 구분

## 4단계: 추가 액션 제안

검색 결과를 바탕으로:
- "이 주차를 복습하려면 `/review 머신러닝 4주차`"
- "이 개념들을 비교하려면 `/compare-notes`"

## 전체 워크플로우

```
1. 키워드 파악
2. 전체 노트 Grep 검색 (컨텍스트 포함)
3. 과목·주차별로 결과 그룹핑
4. 컨텍스트와 함께 정리된 결과 제시
5. 추가 액션 제안
```
