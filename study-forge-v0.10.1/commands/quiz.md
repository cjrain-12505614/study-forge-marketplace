# /quiz 커맨드

강의노트를 기반으로 퀴즈를 한 문제씩 대화형으로 출제하고 채점한다.

## 인자

- `$1` = 과목명 (선택)
- `$2` = 주차 또는 범위 (예: 3, 1-5) (선택)

## 실행

1. `quiz` 스킬의 워크플로우를 실행
2. 객관식/O·X/단답형/코드 출력 문제를 섞어서 생성
3. 한 문제씩: 출제 → 답변 → 즉시 채점 + 해설
4. 종료 시 결과표 + 오답 정리 + 취약 단원 분석
