# /compare-notes 커맨드

두 개 이상의 강의노트를 비교하여 연결 흐름, 공통/차이를 정리한다.

## 인자

- 주차 간: `$1` = 과목명, `$2` = 주차1, `$3` = 주차2
- 과목 간: `$1` = 과목1, `$2` = 과목2, `$3` = 키워드

## 실행

1. `compare-notes` 스킬의 워크플로우를 실행
2. 비교 대상 노트 로드 + 분석
3. 공통 개념 비교표 + 고유 내용 + 발전 흐름 정리
