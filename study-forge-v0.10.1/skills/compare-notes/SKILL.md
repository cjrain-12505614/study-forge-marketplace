# 노트 비교 스킬

두 개 이상의 강의노트를 비교하여 개념의 연결, 발전 흐름, 차이를 정리한다.

## 비교 유형

### 1. 주차 간 비교 (같은 과목)

같은 과목의 다른 주차 노트를 비교:
- 개념의 발전 흐름 (기초 → 심화)
- 이전 주차 개념이 이후에 어떻게 확장되는지
- 예: "2주차 선형 회귀 → 5주차 다중 회귀 → 7주차 정규화"

### 2. 과목 간 비교

다른 과목에서 같은 주제를 다루는 경우:
- 각 과목에서의 관점/깊이 차이
- 예: "머신러닝의 정규화 vs 빅데이터기초수학의 정규화"

## 1단계: 비교 대상 파악

사용자 요청에서 비교 대상을 파악:
- "머신러닝 2주차와 5주차 비교" → 주차 간 비교
- "머신러닝이랑 파이썬데이터분석에서 회귀" → 과목 간 비교
- 구체적이지 않으면 질문

## 2단계: 노트 로드 및 분석

비교 대상 강의노트를 모두 로드하고:
- 공통 키워드 추출
- 각 노트의 주제 구조 파악
- 겹치는 개념과 고유 개념 분류

## 3단계: 비교 결과 작성

### 출력 포맷

```markdown
## 비교: 머신러닝 2주차 vs 5주차

### 연결 흐름
- 2주차 "선형 회귀"가 5주차 "다중 회귀"의 기초
- 2주차의 단일 변수 → 5주차에서 다변수로 확장
- 손실 함수는 동일 (MSE), 최적화 방법이 달라짐

### 공통 개념
| 개념 | 2주차 | 5주차 |
|------|-------|-------|
| 손실 함수 | MSE 정의 | MSE + 정규화 항 추가 |
| 경사하강법 | 기본 원리 | 미니배치, 학습률 스케줄링 |
| 과적합 | 언급만 | 상세 다룸 + 해결법 |

### 2주차에만 있는 내용
- 회귀 분석의 역사적 배경
- 단순 선형 회귀의 해석적 풀이

### 5주차에만 있는 내용
- 다중공선성 문제
- 특성 선택과 차원 축소
- 정규화 (L1, L2)

### 학습 흐름 요약
2주차 기초 → (3~4주차 분류 학습) → 5주차에서 회귀를 확장·심화
```

## 전체 워크플로우

```
1. 비교 대상 파악 (주차 간 or 과목 간)
2. 관련 강의노트 로드
3. 공통/고유 개념 분류
4. 연결 흐름 · 비교표 · 차이점 정리
5. 학습 흐름 요약
```
