# 대화형 예습 스킬

강의교안 PDF를 미리 읽어 핵심 개념을 파악하고, 섹션별로 단계적 예습을 진행한다.
review 스킬과 마찬가지로 한꺼번에 쏟아내지 않고 작은 단위로 진행한다.

## 핵심 원칙

- **한 번에 하나의 주제만** 소개
- 각 주제마다 **사전 지식 확인 질문**을 던진다
- 사용자가 이미 아는 내용이면 빠르게 넘어간다
- 수업에서 배울 내용의 **전체 그림**을 먼저 보여주고, 세부로 들어간다
- 교안의 모든 내용을 설명하지 않음 — **핵심 키워드와 개요** 수준

## review 스킬과의 차이

| 항목 | preview (예습) | review (복습) |
|------|----------------|---------------|
| 자료 | 강의교안 PDF | 강의노트 (작성 완료된) |
| 깊이 | 개요·키워드 수준 | 상세 내용 + 정리 |
| 질문 방향 | "이 개념 들어봤어?" (사전 지식 확인) | "이 개념 설명할 수 있어?" (이해도 확인) |
| 목적 | 수업 전 맥락 잡기 | 수업 후 내용 정착 |

## 1단계: 교안 로드

과목·주차를 파악하고 강의교안 PDF를 이미지로 변환하여 읽는다.

> PDF → 이미지 변환은 poppler의 `pdftoppm`을 직접 부른다 — `pdftoppm -png -r 110 <pdf> <out>/p`

```python
import os, subprocess

SESSION_BASE = '/sessions/{session_id}'
MNT = os.path.join(SESSION_BASE, 'mnt')
SYSTEM_DIRS = {'uploads', '.claude', '.skills', '.local-plugins',
               '.cowork-lib', '.cowork-perm-req', '.cowork-perm-resp'}

def find_course_folders():
    folders = []
    for item in os.listdir(MNT):
        full = os.path.join(MNT, item)
        if not os.path.isdir(full):
            continue
        if item.startswith('.') or item in SYSTEM_DIRS:
            continue
        folders.append({'name': item, 'path': full})
    return folders

def load_lecture_pdf(course_path, week):
    pdf_dir = os.path.join(course_path, '강의교안')
    for f in os.listdir(pdf_dir):
        if f'{week:02d}' in f and f.lower().endswith('.pdf'):
            return os.path.join(pdf_dir, f)
    return None
```

강의교안이 없으면 사용자에게 안내한다.

## 2단계: 교안 구조 파악

교안 이미지를 순차적으로 읽으며 주요 주제(슬라이드 제목)를 파악한다.

- 10~15페이지씩 읽기
- 각 슬라이드의 제목/키워드만 메모
- 전체 주제 목록을 구성

## 3단계: 예습 세션 진행

### 세션 시작

1. "이번 주 강의 주제" 전체 목록을 보여준다 (3~5개 대주제)
2. "어떤 주제부터 볼까요? 전혀 모르는 주제가 있으면 거기서부터 시작할게요"

### 각 주제 진행 패턴

#### A. 주제 소개 (2~3줄)
- 이 주제가 무엇인지, 왜 배우는지
- 이전 주차와의 연결고리 (있으면)
- 핵심 키워드 나열

#### B. 사전 지식 확인
- "이 개념 들어본 적 있어요?"
- "~가 뭔지 알고 있나요?"
- 가볍게 묻고, 모르면 간단히 배경 설명

#### C. 사용자 응답 처리

**이미 아는 경우:**
- "좋아요, 그 배경지식이면 수업 때 잘 따라갈 수 있을 거예요"
- 수업에서 주의 깊게 볼 포인트만 1~2줄 언급
- 다음 주제로

**모르는 경우:**
- 간단한 비유나 예시로 핵심 개념만 소개 (3~5줄)
- 깊이 들어가지 않음 — "수업에서 자세히 배울 내용이에요"
- 사전에 알아두면 좋을 배경 지식 안내

**궁금한 점이 있는 경우:**
- 질문에 답변하되, 예습 수준에서 답할 수 있는 범위로
- "이건 수업에서 더 자세히 다룰 거예요" 가 적절한 경우도 있음

#### D. 다음 주제 전환

## 4단계: 세션 종료

1. **이번 주 핵심 키워드** 한눈에 정리 (5~10개)
2. **수업 전 준비사항** — 미리 알아두면 좋은 것
3. **수업 때 집중할 포인트** — 교수가 강조할 것 같은 부분

## 전체 워크플로우

```
1. 과목·주차 파악 → 강의교안 PDF 이미지 변환
2. 교안 훑어 읽기 → 주제 목록 구성
3. 주제 목록 제시 → 시작점 선택
4. 각 주제: 소개 → 사전 지식 확인 → 보충 → 다음
5. 종료: 핵심 키워드 + 준비사항 + 집중 포인트
```
