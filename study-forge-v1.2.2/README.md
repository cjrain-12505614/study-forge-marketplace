> **v1.0.0 — 5과목 1·2주차를 실제로 완주하며 절차가 안정화되어 1.0으로 올린다.**
> 딥러닝 2주차 `학습평가`·`학습정리` 자동 채록에서 얻은 것을 반영. **퀴즈는 표준 폼이 아니라 `maui` 커스텀 컴포넌트**(선택지 `div.component-data-field`, 버튼 `span.maui-border-button`)이고, ⚠️ **버튼이 문항당 2개**(`정답확인`+`다시풀기`)라 텍스트 필터링하면 이미 채점된 문항을 다시 눌러 헛돈다 — **위치 인덱스** `btns[2k]`로 매핑한다. `el.click()` 단독으로는 반응하지 않아 `pointerdown→mousedown→pointerup→mouseup→click` 디스패치가 필요하고, **async 일괄 처리는 실패**해 문항마다 동기 분할 호출해야 한다. 정답 정규식에 부정 전방탐색을 넣어 버튼 텍스트 `정답확인`을 정답으로 읽는 **오매치 버그**를 막고(기존 절단 버그와 반대 방향), 정답·해설을 **독립 정규식으로 분리**해 해설 없는 참 진술 문항에서 정답까지 잃던 결함을 고쳤다. **거짓 진술 문항에만 해설이 붙는 것이 과목 공통 패턴**임을 확정 — 빈 해설은 추출 실패가 아니다. 상위 항목 수동 이동 수단(**플레이어 우하단 `‹ ›` 화살표**)과 **상호작용 페이지는 자동 전환되지 않는다**는 사실을 신설. 전환 로거 dedup 키에 본문 글자수를 넣어 **채점 전/후를 각각 보존**하고, 콘텐츠 추출을 `.toc-row` 기준으로 통일했다(「가장 긴 텍스트」 휴리스틱은 바깥 강의실 문서를 잡는다). `confirm-toc` v0.6.0.

## 과목 폴더 구조

마운트된 폴더를 과목 폴더로 자동 인식한다. 폴더명 형식은 자유.

```
과목명/
├── CLAUDE.md          # 학습지원 가이드
├── 강의교안/          # 주차별 PDF
├── 강의녹음/          # 주차별 MP3
├── 강의영상/          # 주차별 MP4 (선택)
├── 스크립트/          # 변환된 TXT (자동 생성)
├── 실습/              # 실습 PDF (선택)
└── 강의노트/          # 강의노트, 플래시카드, 시험정리 등
```

## 학습 사이클

```
뭐 하지?  →  /ta (조교가 현황 분석 후 다음 할 일 제안)
수업 전  →  /preview (교안 기반 예습)
수업 중  →  /new-week 또는 /collect-week + /confirm-toc + (자막 없는 항목만) /transcribe + /create-note
수업 후  →  /review → /quiz → /flashcard
시험 전  →  /study-plan → /exam-summary → /mock-exam
수시     →  /solve (문제 풀이) · /search (키워드 검색) · /progress (현황)
```

## 설치

`.plugin` 파일을 Cowork에서 설치.

## 의존성

- 다글로(daglo) MCP + `ffmpeg` — 전사(클라우드·유료) 및 오디오/영상 처리(로컬)
- `poppler` (`pdftoppm`) — PDF → 이미지 (맥 `brew install poppler`)
- `pdfminer.six` — PDF 텍스트 추출
- `playwright` + Chromium — 다이어그램 PNG 렌더링 (맥은 시스템 한글 폰트로 충분)

의존성은 각 스킬 실행 시 자동 설치.
