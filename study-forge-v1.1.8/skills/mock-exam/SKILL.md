# 모의시험 스킬

시험 범위의 강의노트를 기반으로 실전과 유사한 모의시험을 생성하고, 채점 후 취약 단원을 분석한다.

## quiz와의 차이

| 항목 | quiz | mock-exam |
|------|------|-----------|
| 목적 | 일상적 복습 | 시험 직전 실전 연습 |
| 범위 | 1주차 단위 | 시험 범위 전체 |
| 문제 수 | 10문제 | 20~30문제 |
| 진행 방식 | 한 문제씩 + 즉시 해설 | 전체 풀기 → 일괄 채점 |
| 시간 | 제한 없음 | 제한 시간 안내 (선택) |
| 결과 | 간단 요약 | 상세 분석 + 취약 단원 |

## 1단계: 시험 설정

### 파악할 정보
- 과목명
- 시험 범위 (주차)
- 문제 수 (기본 25문제)
- 시험 형식 (사용자에게 확인):
  - 객관식 위주
  - 혼합 (객관식 + 단답형 + 서술형)
  - 코딩 포함

## 2단계: 출제

### 출제 원칙

- 시험 범위 내 **모든 대단원에서 최소 2문제** 출제
- 난이도 배분: 기본(40%) / 응용(40%) / 심화(20%)
- 문제 배치: 쉬운 것부터 어려운 순서
- 주차별 비중은 내용 분량에 비례

### 출제 형식

```markdown
# [과목명] 모의시험
## 범위: 1~7주차 | 문제: 25문제

---

**1.** [문제 본문]

① [보기1]  ② [보기2]  ③ [보기3]  ④ [보기4]

---

**2.** [문제 본문]

① [보기1]  ② [보기2]  ③ [보기3]  ④ [보기4]

---

(... 계속 ...)
```

### 전체 문제를 한 번에 제시

quiz와 달리 **모든 문제를 한 번에 제시**하고, 사용자가 전체를 풀어서 답을 제출하게 한다.

## 3단계: 답안 수집

사용자에게 답안 입력 방식을 안내:
- "1: ③, 2: ①, 3: O, ..." 형식
- 또는 번호만 나열: "3, 1, O, ..."

## 4단계: 채점

### 채점표

```markdown
## 채점 결과

| # | 정답 | 내 답 | 결과 | 주제 |
|---|------|-------|------|------|
| 1 | ③ | ③ | O | 선형회귀 |
| 2 | ① | ② | X | 정규화 |
| ... | ... | ... | ... | ... |

### 총점: 18/25 (72%)
```

## 5단계: 상세 분석

### 주제별 정답률

```markdown
### 주제별 분석

| 주제 (주차) | 출제 | 정답 | 정답률 |
|-------------|------|------|--------|
| 선형회귀 (2주차) | 4 | 4 | 100% |
| 분류 (3주차) | 3 | 2 | 67% |
| 정규화 (4주차) | 3 | 1 | 33% ← 취약 |
| ... | ... | ... | ... |
```

### 취약 단원 분석

정답률 60% 미만인 주제를 취약 단원으로 분류하고:
1. 해당 주제에서 틀린 문제를 모아 해설 제공
2. 핵심 개념 다시 정리
3. 복습 경로 제안

### 추천 액션

```markdown
### 추천
1. `/review` 4주차 — 정규화 개념 집중 복습
2. `/quiz` 4주차 — 정규화 관련 추가 연습
3. `/flashcard` 3-4주차 — 분류·정규화 핵심 용어 암기
4. `/mock-exam` 재응시 — 1~2일 후 다시 풀어보기
```

## 6단계: 오답노트 저장 (선택)

사용자가 원하면 오답과 해설을 파일로 저장:
- 파일명: `모의시험-오답노트-{날짜}.md`
- 저장 위치: 강의노트/ 폴더

## 전체 워크플로우

```
1. 과목·범위·문제 수·형식 파악
2. 강의노트 로드 → 문제 생성 (전체 한 번에)
3. 사용자 풀이 → 답안 수집
4. 일괄 채점 + 채점표
5. 주제별 정답률 + 취약 단원 분석
6. 오답 해설 + 복습 추천
7. (선택) 오답노트 파일 저장
```
