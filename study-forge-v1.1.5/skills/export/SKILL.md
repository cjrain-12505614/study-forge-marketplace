# 강의노트 형식 변환 스킬

마크다운 강의노트를 PDF, DOCX, PPTX 등으로 변환한다.

## 지원 형식

| 형식 | 용도 | 방법 |
|------|------|------|
| PDF | 인쇄, 제출 | Cowork의 pdf 스킬 활용 |
| DOCX | 편집, 제출 | Cowork의 docx 스킬 활용 |
| PPTX | 발표, 요약 | Cowork의 pptx 스킬 활용 |

## 1단계: 대상 파악

- 과목, 주차 (또는 범위)
- 출력 형식 (PDF/DOCX/PPTX)
- 특별 요구사항 (페이지 크기, 폰트, 여백 등)

## 2단계: 강의노트 로드

해당 주차의 강의노트 마크다운을 로드한다.
여러 주차를 합쳐서 하나의 문서로 만들 수도 있다.

## 3단계: 형식 변환

### PDF 변환
- Cowork의 `pdf` 스킬을 활용
- 코드블록, 표, 수식이 잘 렌더링되도록 처리

### DOCX 변환
- Cowork의 `docx` 스킬을 활용
- 마크다운 헤더 → Word 제목 스타일 매핑
- 목차 자동 생성 가능

### PPTX 변환
- Cowork의 `pptx` 스킬을 활용
- 대단원(#) → 슬라이드 구분
- 핵심 내용만 추출하여 슬라이드에 배치
- 전체 내용이 아닌 요약 형태

## 4단계: 저장 및 제공

변환된 파일을 과목 폴더에 저장:
- 파일명: `{주차}-강의노트.{확장자}`
- computer:// 링크로 제공

## 전체 워크플로우

```
1. 과목·주차·형식 파악
2. 강의노트 마크다운 로드
3. 해당 형식의 Cowork 스킬 활용하여 변환
4. 과목 폴더에 저장 + 링크 제공
```
