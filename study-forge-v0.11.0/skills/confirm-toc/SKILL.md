# 학습목차 확정 스킬 (추정 금지)

`##(N)` 하위 목차명을 **추측 없이** 확정한다.

## 시작 전 필수

1. 워크스페이스 `CLAUDE.md`와 **과목 폴더 `CLAUDE.md`**를 읽는다
2. 같은 종류의 **기존 산출물을 열어 형식을 확인**한다
3. 확인할 수 없는 값은 **비워 두고 채울 방법을 안내**한다 — 그럴듯한 추정값 금지

## ⛔ 절대 하지 말 것

**1. 강의를 재생하지 말 것**

목차를 알아내려고 플레이어를 열면 **수강 기록·진도·출석이 올라간다.** 학교는 대리출석을 금지하고 본인인증 로그인을 의무화하고 있다. **재생은 사용자 본인의 행위**다.

특히 **영상이 끝나면 자동으로 다음 영상으로 넘어간다.** 플레이어를 열어둔 채 방치하면 `To do` 항목까지 연쇄로 재생된다. 이미 `완료`된 항목이라도 열었으면 **즉시 닫는다.**

부득이 열었다면 곧바로 정지시킨다.

```javascript
[...document.querySelectorAll('iframe')].forEach(f => {
  try { f.contentDocument?.querySelectorAll('video,audio')
          .forEach(v => { v.pause(); v.autoplay = false; }); } catch(e) {}
});
```

**2. 전사 내용으로 목차명을 지어내지 말 것**

전사 도입부가 "머신러닝의 개념에 대해서 살펴보겠습니다"라고 해서 목차명이 `머신러닝`인 것은 아니다. **그럴듯하지만 틀린 라벨**이 만들어진다(2026-08-31 실제 사고 — 전량 오답).

## 목차 구조 — 2단이다

| 단계 | 위치 | 예 |
|---|---|---|
| **상위 목차** `#` | 강의실 **주차 목록에 바로 보임** | `들어가기` · `수업 계획` · `딥러닝 소개` · `실습환경 소개` · `평가하기` · `정리하기` |
| **하위 목차** `##(N)` | 상위 항목 **안으로 들어가야 나옴** | `들어가기` → `인트로`, `학습개요` |

- **MP3 1개 = 동영상 1개 = `##(N)` 1개**
- 상위 항목 수와 MP3 수는 **일치하지 않는다** (딥러닝 1주차: 상위 4개 vs MP3 7개)
- 하위 목차는 **앞 영상을 끝까지 봐야 다음 상위 항목이 열리는 순차 잠금** 구조다.
  배속도 통하지 않는다(출석이 실시간 기준) → **목차 수집 속도 = 실제 수강 시간**.
  한 세션에 다 모으려 하지 말고 사용자 진도에 맞춰 나눠 받는다

## 1단계: 상위 목차 읽기 (재생 없음)

주차 아코디언을 펼치면 상위 항목이 보인다. 여기까지는 재생이 아니므로 안전하다.

```javascript
const hs = [...document.querySelectorAll('*')]
  .filter(e => e.children.length === 0 && /^\d+주차$/.test((e.innerText||'').trim()));
let box = hs[0];
for (let i = 0; i < 8 && box; i++) {
  if ((box.innerText||'').includes('To do')) break;
  box = box.parentElement;
}
box.innerText.replace(/\s*To do\s*/g, '\n').replace(/\n{2,}/g, '\n').trim()
```

아이콘으로 종류를 구분한다.

- **▣ 웹페이지 아이템** — 과목 안내·평가 안내 등. 영상·MP3 없음
- **▶ 자료 아이템** — 동영상. 이 안에 하위 목차가 있음

## 2단계: 하위 목차 + 영상 길이 읽기

**사용자가 수강하는 동안** 플레이어 패널을 읽는다. 상위 항목별로 한 번씩.

```javascript
[...document.querySelectorAll('iframe')].flatMap(f => {
  try {
    const d = f.contentDocument; if (!d) return [];
    const toc = [...d.querySelectorAll('.toc-row')]
      .map(e => e.innerText.replace(/\s+/g,' ').trim()
                + (e.className.includes('selected') ? ' ◀' : ''));
    const vs = [...d.querySelectorAll('video')]
      .map(v => ({ dur: isFinite(v.duration) ? Math.round(v.duration) : null,
                   cur: Math.round(v.currentTime||0) }));
    return (toc.length || vs.length) ? [{toc, vs}] : [];
  } catch(e) { return []; }
})
```

- `.toc-row` 첫 항목이 **상위 목차**, 나머지가 **하위 목차**
- `video.duration` 이 현재 재생 중인 하위 항목의 길이
- 진행률(`cur/dur`)로 다음 항목이 언제 열릴지 사용자에게 알릴 수 있다

주기적 감시가 필요하면 `/loop 2m` 로 위 스니펫을 돌린다. **읽기만 하고 조작하지 않는다.**

## 3단계: MP3 길이와 대조 — 확정 근거

**영상 길이와 MP3 길이는 초 단위로 정확히 일치한다.** 7건 전수 검증에서 오차 최대 1초(반올림). 이것이 매칭의 확정 근거이며, 여기에 맞으면 추측이 아니다.

```bash
for f in 강의녹음/*_{주차}_*.mp3; do
  printf "%s %s\n" "$(ffprobe -v error -show_entries format=duration \
    -of default=nw=1:nk=1 "$f" | cut -d. -f1)" "$(basename "$f")"
done | sort -n
```

| 하위 목차 | 영상 | MP3 | 판정 |
|---|---:|---:|---|
| 학습개요 | 29초 | `_01` 29초 | ✅ |
| 오리엔테이션 | 769초 | `_02` 769초 | ✅ |
| 머신러닝 | 1358초 | `_04` 1357초 | ✅ 반올림 1초차 |

**어떤 MP3와도 길이가 맞지 않으면 MP3 없는 항목**으로 처리한다.

## 4단계: MP3 없는 항목 처리

| 항목 | 특징 | 처리 |
|---|---|---|
| **인트로** | 매 주차 **첫 영상**, 18초 내외 타이틀 영상 | `##` 번호 없이 기록. 첫 MP3는 그다음인 `학습개요` |
| **학습평가** | 퀴즈 페이지, `<video>` 요소 자체가 없음 | **채록 필수** (아래) |
| **학습정리** | 요약 슬라이드, `<video>` 없음 | **채록 필수** (아래) |

> 첫 MP3를 무조건 `인트로`로 붙이면 **한 칸씩 밀린다.** 길이로 확인할 것.

## 5단계: 학습평가·학습정리 채록 — 유일한 경로

두 구역은 **MP3가 없어 전사로 절대 복원되지 않는다.** 지금 받아두지 않으면 강의노트를 완성할 수 없다.

- **학습평가** — 퀴즈를 풀어야 다음으로 넘어가는 구조다. 사용자가 문항을 올리면
  문제·정답·해설을 스크립트에 적어둔다. 정답 판정은 전사·교안 근거를 들어 설명한다
- **학습정리** — 요약 슬라이드. 이미 수강 완료한 페이지라면 열어서 읽어도 진도 영향이 없다

```javascript
// 중첩 iframe 안쪽 본문 추출
let out = '';
(function dig(d) {
  try {
    const t = (d.body?.innerText || '').trim();
    if (t.includes('이번 주차에서 학습한')) out = t;
    [...d.querySelectorAll('iframe')].forEach(f => f.contentDocument && dig(f.contentDocument));
  } catch(e) {}
})(document);
out
```

## 6단계: 스크립트에 반영

`prepare-script` 형식을 그대로 따른다. 확정된 것만 채우고 **미확인은 빈칸으로 둔다.**

```
<{과목} {N}주차 학습목차>

# 들어가기
## 인트로               ← 영상 18초 · MP3 없음(타이틀 영상)
## (1)학습개요          ← 영상 29초 = {코드}_1_01.mp3 29초
---
# 수업 계획
## (2)오리엔테이션      ← 영상 769초 = {코드}_1_02.mp3 769초
---
# 평가하기
## 학습평가             ← 퀴즈 페이지, 영상·MP3 없음
---
# 정리하기
## 학습정리             ← 요약 슬라이드, 영상·MP3 없음
```

### ⚠️ 파일 수정 시 인덱스 기반 편집 금지

학습목차 구역과 본문 구역에 **`## 학습평가` 같은 동일 문자열이 두 번** 나온다. `s.index('## 학습평가')` 로 자르면 목차 쪽을 잡아 **파일 뒷부분이 통째로 날아간다**(2026-08-31 2회 발생).

- **소스(전사 파일)에서 재생성**하는 방식을 기본으로 한다
- 부분 수정이 필요하면 `←` 주석까지 포함한 **유일한 문자열**을 앵커로 쓴다
- 수정 후 **구역 개수와 파일 크기를 검증**한다

## 7단계: 보고

- 확정된 `##(N)` 과 근거(영상 길이 = MP3 길이)
- 미확정 항목과 **확인 방법** — "N주차 X 항목을 수강하시면 읽어서 채우겠습니다"
- 채록된 학습평가 문항 수 · 학습정리 유무
