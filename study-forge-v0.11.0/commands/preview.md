# /preview 커맨드

강의교안 PDF를 미리 읽고 대화형으로 예습 세션을 진행한다. 주제별로 핵심 키워드 소개 → 사전 지식 확인 → 보충 설명 순서.

## 인자

- `$1` = 과목명 (선택)
- `$2` = 주차 번호 (선택)

## 실행

1. `preview` 스킬의 워크플로우를 실행
2. 강의교안 PDF → 이미지 변환 → 주제 파악
3. 주제별: 소개 → 사전 지식 질문 → 보충
4. 종료: 핵심 키워드 + 수업 전 준비사항
