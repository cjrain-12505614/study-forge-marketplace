# /exam-summary 커맨드

여러 주차 강의노트를 종합하여 시험용 요약 정리본을 생성한다.

## 인자

- `$1` = 과목명 (선택)
- `$2` = 주차 범위 (예: 1-7, 8-14) (선택)

## 실행

1. `exam-summary` 스킬의 워크플로우를 실행
2. 범위 내 강의노트 전체 로드
3. 주제별로 재구성 (주차순 나열이 아님)
4. 비교표 + 공식 모음 포함
5. 강의노트/ 폴더에 저장 + 링크 제공
