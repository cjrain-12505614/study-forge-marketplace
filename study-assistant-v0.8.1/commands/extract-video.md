# /extract-video 커맨드

강의영상 MP4에서 슬라이드 프레임을 캡처하고 오디오를 MP3로 추출한다.

## 인자 처리

- `$1` = 과목명 (선택, 없으면 과목 목록에서 선택)
- `$2` = 주차 번호 (선택, 없으면 질문)

## 실행

1. `extract-video` 스킬의 워크플로우를 실행한다
2. 강의영상/ 폴더에서 해당 주차 MP4 탐색
3. ffmpeg으로 오디오 추출 → 강의녹음/ 폴더에 MP3 저장
4. 장면 전환 감지로 슬라이드 프레임 캡처
5. 타임스탬프 매핑 결과 제공

## 다음 단계 안내

- 추출된 MP3 → `/transcribe`로 스크립트 변환
- 슬라이드 프레임 → `/create-note`에서 강의교안 대신 참조 가능
- 또는 `/new-week`으로 전체 워크플로우 실행
