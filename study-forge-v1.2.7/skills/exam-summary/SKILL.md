# 시험 범위 요약 정리 스킬

여러 주차의 강의노트를 종합하여 시험용 요약 정리본을 생성한다.

## 핵심 원칙

- 요약이지만 **시험 출제 가능한 내용은 빠뜨리지 않는다**
- 주차별 나열이 아닌 **주제별로 재구성**
- 연관 개념끼리 묶어서 **흐름을 보여준다**
- 단순 나열보다 **비교표, 분류 체계** 활용

## 1단계: 범위 파악

과목과 시험 범위(주차)를 파악한다.
- 예: "중간고사 1~7주차", "기말 8~14주차"
- 범위를 모르면 사용자에게 질문

## 2단계: 강의노트 전체 로드

```python
import os

def load_notes_range(course_path, start_week, end_week):
    """범위 내 모든 강의노트 로드"""
    note_dir = os.path.join(course_path, '강의노트')
    notes = {}
    for f in sorted(os.listdir(note_dir)):
        if not f.endswith('.md'):
            continue
        for w in range(start_week, end_week + 1):
            if f'{w:02d}' in f:
                filepath = os.path.join(note_dir, f)
                with open(filepath, 'r', encoding='utf-8') as fh:
                    notes[w] = fh.read()
    return notes
```

누락된 주차가 있으면 사용자에게 안내한다.

## 3단계: 주제별 재구성

주차별로 나열하지 않고 내용의 흐름에 따라 재구성한다.

### 구성 방식

1. **주제 맵 작성** — 전체 범위에서 다루는 대주제 목록
2. **주제별 정리** — 각 주제에 대해:
   - 핵심 정의
   - 세부 내용 (중요도순)
   - 관련 공식/코드
   - 다른 주제와의 연결
3. **비교표** — 유사 개념 비교 (2개 이상 비교 대상이 있을 때)
4. **공식 모음** — 시험에 나올 수 있는 공식 한곳에 정리

## 4단계: 요약본 작성

### 서식 규칙

- 개조식 작성, 마침표 금지
- 코드블록은 최상단 레벨에 배치
- 수식은 LaTeX 코드블록
- 각 주제 아래 "(n주차)" 표시로 원래 출처 표시 — 세부 복습 시 참고용

### 마크다운 구조

```markdown
# [과목명] 시험 정리 (1~7주차)

## 주제 1: [대주제명]

### [세부 주제] (2주차)
- 핵심 내용
- 핵심 내용

### [세부 주제] (3주차)
- 핵심 내용

---

## 주제 2: [대주제명]
...

---

## 핵심 비교표

| 구분 | A | B | C |
|------|---|---|---|
| 특징 | ... | ... | ... |

---

## 공식 모음
...
```

## 5단계: 저장

파일명: `시험정리-{범위}.md` (예: `시험정리-01~07주차.md`)
저장 위치: 과목 폴더의 강의노트/ 디렉토리

## 전체 워크플로우

```
1. 과목·시험 범위 파악
2. 범위 내 강의노트 전체 로드
3. 주제별 재구성 (주차순이 아닌 흐름순)
4. 비교표, 공식 모음 포함한 요약본 작성
5. 강의노트/ 폴더에 저장 + 링크 제공
```
