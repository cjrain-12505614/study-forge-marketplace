# /transcribe 커맨드

지정한 과목·주차의 MP3 파일을 다글로(daglo) MCP로 텍스트 변환하여 스크립트 TXT의 `##(N)` 구역에 삽입한다.

> ⛔ **이 커맨드는 폴백이다 — 실행 전에 자막부터 확인한다.** 강의실 공식 자막이 이 커맨드의 출력보다 정확하고(이산값 4/4 정확 · 규범 표기 40:0), **무료이며 클라우드 업로드가 없다.** 자막은 `/confirm-toc`이 수확한다. **자막이 확보된 항목은 전사하지 않는다.**

> ⚠️ **다글로 전사는 유료 크레딧을 소모하고 파일을 클라우드로 업로드한다.** 전사를 시작하기 전에 **반드시 대상 파일 목록·개수·옵션을 제시하고 사용자 승인을 받는다.** 승인 없이 `start_transcription(dry_run=False)` 를 호출하지 않는다.

## 인자 처리

- `$1` = 과목명 (선택, 없으면 과목 목록에서 선택)
- `$2` = 주차 번호 (선택, 없으면 변환되지 않은 MP3 목록 제시)

## 실행

1. `transcribe` 스킬의 워크플로우를 실행한다
2. 과목 폴더의 강의녹음/ 디렉토리에서 MP3 파일을 탐색 (VM 경로 → Mac 절대경로 변환)
3. `upload_file` 로 대상 MP3를 일괄 업로드 — **무료**, `fileMetaId` 수집
4. ⚠️ **승인 게이트** — 대상·개수·옵션을 제시하고 사용자 승인을 받는다 (여기서 1회만)
5. `start_transcription(dry_run=False)` 로 일괄 전사 시작 — **유료**
   - `language='ko-KR'`, `topic` 은 전공에 맞게, `use_dictionary=True`
   - `use_speaker_diarization=False` — 강의는 단일 화자, 화자 라벨이 `##(N)` 구역을 오염시킴
6. `get_file_status` 폴링 → `get_transcript(with_time=False)` 로 평문 회수
7. `whisper-terms.txt` 를 참조한 LLM 후처리 (전문 용어 교정 + 환각 제거) — **MP3 전사 경로에 한해 생략 금지**
   - 다글로에는 `initial_prompt` 가 없어 엔진이 과목 용어를 미리 알지 못하므로 이 단계가 특히 중요하다
   - ⛔ **자막에서 온 본문에는 적용하지 않는다** — 규범 표기가 이미 일관이라 후처리가 표기를 되돌린다
   - ⛔ **용어집을 정답으로 삼아 기계 정규화하지 말 것** — 딥러닝 용어집의 `에폭`은 틀렸고 강의·자막 모두 `에포크`다. 용어집은 **의심 후보 목록**이며 강의 실제 표기가 우선한다
8. 스크립트 TXT의 `##(N)` 구역에 교정된 전사 텍스트 삽입
9. 변환 결과를 사용자에게 안내

## 주의

- 이미 전사가 삽입된 스크립트는 **재전사하지 않는다** (불필요한 과금 방지)
- 폴링이 타임아웃돼도 서버 전사는 계속되므로 `fileMetaId` 를 보존하면 나중에 회수 가능
- 사용자가 전사를 거부하면 업로드된 파일은 그대로 두고 종료한다 (전사만 안 하면 과금되지 않음)
- 본문 확보 계층은 **3단**이다 — ① **강의실 공식 자막**(정본 · 무료 · `/confirm-toc`) → ② 다글로 MP3 전사(유료) → ③ whisper-cli 로컬(`/stt --local` · 최하위)
- ③은 의미 반전(`금방 할 수 없고` → `금방 할 수 있고`)·고유명사 뭉갬(`Quick-Win` → `퀵윈`)·문장 유실이 실측된 최후 수단이다
- 다글로 장애·토큰 만료(`401`) 시에는 ①을 먼저 시도하고, 그래도 안 되면 ③으로 내려간다
