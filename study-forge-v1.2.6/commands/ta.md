# /ta 커맨드

전체 과목의 학습 상태를 자동 진단하고, 지금 해야 할 작업을 구체적으로 제안한다.

## 인자

- 없음 (전체 과목 자동 스캔)

## 실행

1. `ta` 스킬의 워크플로우를 실행
2. 전체 과목 폴더 스캔 → 주차별 상태 판정
   - 파일 존재만으로 `완료`를 주지 않는다 — 노트가 있는 주차는 **스크립트 학습평가 채록본과 노트를 create-note 기준(확인 5 · 10단계)으로 대조**한다
     - 채록본 미준비(정답확인 채점 기록 없음·공식 정답/해설 미확인·추정 표지) → **`학습평가_정답필요`** (→ `/confirm-toc` 학습평가 정답확인 회수 — 완료 주차는 스킬이 `평가하기`를 직접 연다 → 노트 학습평가 절 갱신)
     - 채록본은 준비됐는데 노트가 다름 → **`학습평가_노트갱신`** (→ `/create-note` 10단계 보강 · 노트 학습평가 절만 갱신 · 강의실 불필요)
     - 스크립트를 대조할 수 없으면 노트 단독 표지 검사(추정·미확인·미확보 표기 · 정답 줄 누락)로 대체한다
3. 우선순위에 따라 1~3개 작업 제안
4. 사용자가 선택하면 해당 커맨드를 즉시 실행
