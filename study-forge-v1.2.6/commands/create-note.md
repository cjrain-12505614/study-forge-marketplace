# /create-note 커맨드

지정한 과목·주차의 스크립트, 강의교안, 실습 자료를 종합하여 마크다운 강의노트를 작성한다.

## 인자 처리

- `$1` = 과목명 (선택, 없으면 과목 목록에서 선택)
- `$2` = 주차 번호 (선택, 없으면 노트가 없는 주차 목록 제시)

## 전제 조건

- 스크립트/ 폴더에 해당 주차 TXT 파일이 있어야 함
- 스크립트 상단에 학습목록이 정리되어 있으면 더 좋은 결과물이 나옴
- 목차에 `## 학습평가`가 있으면 **스크립트 본문 `## 학습평가` 채록본에 문항별 공식 정답과 공식 해설 원문(또는 `공식 해설 없음` 명시)이 있어야 함** — 정답 줄이 없거나 추정·미확인·미확보 표기가 있으면 노트를 쓰지 않고 `/confirm-toc`로 먼저 회수한다(스킬 0단계 확인 5). 목차에 `# 평가하기`가 없는 주차(AWS)는 해당 없음
- 스크립트가 없으면 먼저 `/confirm-toc`(목차 확정·자막 수확·학습평가 회수)를 안내하고, 자막이 없는 항목만 `/transcribe`(⚠️유료·폴백)로 보낸다

## 실행

1. `create-note` 스킬의 워크플로우를 실행한다
2. 스크립트 TXT + 강의교안 PDF + 실습 PDF를 읽음
3. CLAUDE.md의 서식 규칙에 따라 마크다운 강의노트 작성
   - **학습평가 절**은 confirm-toc가 회수한 **공식 정답 + 공식 해설 원문(「」) + 강의 근거 보충**으로 쓴다 — 정답 줄은 `**정답** O`(콜론 없음), 해설 첫 불릿은 `- 공식 해설 — 「원문」` 또는 `- 공식 해설이 제공되지 않은 문항 — 아래는 강의 내용을 근거로 정리한 것`
   - ⛔ 「(추정)」·해설 유무 패턴으로 짐작한 정답 금지 · 채점 Y/N·선택 방식은 노트에 넣지 않는다(스크립트·과목 문서에만)
4. 강의노트/ 폴더에 `{00주차}-강의노트.md` 형식으로 저장
5. computer:// 링크로 결과물 제공

## 이미 노트가 있는 경우

해당 주차 강의노트가 이미 존재하면 사용자에게 덮어쓸지 확인한다.
