# /flashcard 커맨드

강의노트에서 핵심 개념을 추출하여 플래시카드를 생성한다.

## 인자

- `$1` = 과목명 (선택)
- `$2` = 주차 또는 범위 (예: 3, 1-5) (선택)

## 실행

1. `flashcard` 스킬의 워크플로우를 실행
2. 강의노트에서 핵심 개념 추출
3. 질문-답변 카드 생성 (주차당 15~25개)
4. 마크다운 파일로 저장 (Anki CSV도 요청 시 제공)
5. computer:// 링크로 파일 제공
