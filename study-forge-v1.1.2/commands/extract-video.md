# /extract-video 커맨드

강의영상 MP4에서 슬라이드 프레임을 캡처하고 오디오를 MP3로 추출한 뒤, 다글로(daglo) MCP로 전사하여 스크립트 TXT의 `##(N)` 구역에 삽입한다.

> ⚠️ **다글로 전사는 유료 크레딧을 소모하고 파일을 클라우드로 업로드한다.** 전사를 시작하기 전에 **반드시 대상 파일 목록·개수·옵션을 제시하고 사용자 승인을 받는다.** 승인 없이 `start_transcription(dry_run=False)` 를 호출하지 않는다.
>
> 프레임 캡처와 오디오 추출(ffmpeg)은 **전부 로컬·무료**다. 과금 지점은 전사 시작뿐이므로, 사용자가 전사를 거부해도 프레임 작업은 단독으로 수행할 수 있다.

## 인자 처리

- `$1` = 과목명 (선택, 없으면 과목 목록에서 선택)
- `$2` = 주차 번호 (선택, 없으면 질문)

## 실행

1. `extract-video` 스킬의 워크플로우를 실행한다
2. 강의영상/ 폴더에서 해당 주차 MP4 탐색
3. ffmpeg으로 오디오 추출 → 강의녹음/ 폴더에 MP3 저장 (이미 있으면 건너뜀) — **로컬·무료**
4. `upload_file` 로 MP3 일괄 업로드 — **무료**, `fileMetaId` 수집
5. ⚠️ **승인 게이트** — 대상·개수·옵션을 제시하고 사용자 승인을 받는다 (여기서 1회만)
6. `start_transcription(dry_run=False)` 로 일괄 전사 시작 — **유료**
   - `language='ko-KR'`, `use_dictionary=True`
   - `use_speaker_diarization=False`, 회수는 `with_time=False` — 화자 라벨·타임스탬프가 `##(N)` 구역을 오염시킴
7. **전사 대기 중 병행**: 장면 전환 감지로 슬라이드 프레임 캡처 — 로컬·무료
8. `get_file_status` 폴링 → `get_transcript(with_time=False)` 로 평문 회수
9. `whisper-terms.txt` + **프레임에서 읽어낸 화면 속 용어**를 참조한 LLM 후처리 — **생략 금지**
10. 스크립트 TXT의 `##(N)` 구역에 교정된 전사 텍스트 삽입
11. 타임스탬프 매핑 결과 제공

## 주의

- 이미 전사가 삽입된 스크립트는 **재전사하지 않는다** (불필요한 과금 방지)
- 사용자가 전사를 거부하면 **프레임 캡처만 수행**하고, 전사가 필요한 후속 단계는 중단한 뒤 상황을 알린다
- 다글로 장애·토큰 만료(`401`) 시에는 스킬 문서의 「폴백」 절차를 따른다

## 다음 단계 안내

- 전사 텍스트는 이미 스크립트 TXT의 `##(N)` 아래에 삽입됨 → `/prepare-script`로 학습목차 추가
- 슬라이드 프레임 → `/create-note`에서 강의교안 대신 참조 가능
- 또는 `/new-week`으로 전체 워크플로우 실행
