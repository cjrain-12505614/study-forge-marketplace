# /review 커맨드

강의노트를 기반으로 대화형 복습 세션을 시작한다. 한 섹션씩 설명 → 질문 → 피드백 → 다음 순서로 진행한다.

## 인자 처리

- `$1` = 과목명 (선택)
- `$2` = 주차 번호 (선택)

## 실행

1. `review` 스킬의 워크플로우를 실행한다
2. 강의노트를 섹션별로 분리
3. 각 섹션을 순서대로: 핵심 내용 → 이해도 질문 → 피드백
4. 사용자 질문에 충분히 답변 후 다음 섹션으로
5. 종료 시 요약 + 취약 포인트 정리
