# 문제 풀이 스킬

수업 내용에 포함되는 문제를 텍스트 또는 이미지로 입력받아, 문제를 정형화하고 정답과 해설을 제공한다.

## 1단계: 입력 판별

사용자가 문제를 제공하는 방식은 두 가지이다.

### 텍스트 입력
- 사용자가 문제 텍스트를 직접 타이핑하거나 복사-붙여넣기로 전달
- 보기가 포함된 경우와 주관식 문제를 모두 처리

### 이미지 입력
- 사용자가 문제 스크린샷, 사진, PDF 캡처를 첨부
- Read 도구로 이미지를 시각적으로 읽어 문제 내용을 파악
- 이미지 속 텍스트, 수식, 그래프, 표 등을 정확하게 인식

```python
# 이미지 입력 처리
# uploads 폴더에 업로드된 이미지를 Read 도구로 읽기
# Read(file_path='/sessions/{session_id}/mnt/uploads/문제사진.png')
# → 시각적으로 문제 내용을 파악
```

## 2단계: 문제 유형 판별

입력된 문제의 유형을 판별한다:

- **객관식** — 보기(①②③④ 또는 1.2.3.4.)가 있는 문제
- **O/X** — 참/거짓 판별 문제
- **단답형** — 짧은 답을 요구하는 문제
- **서술형** — 풀이 과정을 요구하는 문제
- **코딩** — 코드 작성 또는 출력 결과를 묻는 문제

## 3단계: 문제 재정의

원본 문제를 정형화된 포맷으로 재구성한다.

### 재정의 규칙

- 문제 본문을 명확하게 다시 작성
- 보기가 있으면 ①②③④ 형식으로 통일
- 원본에서 불명확하거나 잘린 부분이 있으면 표시
- 수식은 LaTeX 코드블록으로 작성

### 출력 포맷

```markdown
## 문제 재정의

**과목**: [과목명] (담당교수: [교수명])
**시험**: [시험 구분]
**문제 N번** ([문제유형], [배점])

> [문제 본문]

| 보기 | 내용 |
|------|------|
| ① | [보기 1] |
| ② | [보기 2] |

---

## 정답: [번호 또는 답]

## 해설

[왜 정답인지 설명]

[객관식이면 오답 보기 각각에 대한 분석]

## 출처

| 과목 | 주차 | 섹션 |
|------|------|------|
| [과목명] | [N주차] | [해당 섹션/학습단계 제목] |
```

## 4단계: 정답 도출 및 해설

### 정답 도출
- 강의노트가 있으면 관련 내용을 참조하여 정답의 근거를 강의 내용에서 찾음
- 강의노트가 없으면 일반 지식으로 풀이

### 해설 작성 원칙
- 정답인 이유를 먼저 설명
- 객관식이면 오답인 보기 각각에 대해 왜 틀린지 간단히 설명
- 관련 핵심 개념을 요약 (2~3줄)

### 출처 표시 (필수)

해설 마지막에 반드시 **출처** 섹션을 추가한다. 출처는 아래 우선순위로 결정:

1. **강의노트가 있는 경우**: Grep 도구로 키워드를 검색하여 해당 주차와 섹션(## 헤더)을 특정
2. **강의노트가 없지만 과목이 특정된 경우**: 미리알림 또는 교안 정보를 기반으로 추정 주차 표시
3. **과목 미특정**: "일반 지식" 표기

### 강의노트 출처 탐색 방법

```python
import os

SESSION_BASE = '/sessions/{session_id}'
MNT = os.path.join(SESSION_BASE, 'mnt')
SYSTEM_DIRS = {'uploads', '.claude', '.skills', '.local-plugins',
               '.cowork-lib', '.cowork-perm-req', '.cowork-perm-resp'}

def find_source_in_notes(keywords):
    """전체 과목 강의노트에서 키워드를 검색하여 출처를 반환"""
    # Grep 도구로 전체 강의노트 검색
    # pattern: 키워드
    # path: /sessions/{session_id}/mnt/
    # glob: "**/강의노트/*.md"
    # output_mode: "content" (-B 2 -A 2로 컨텍스트 확보)
    #
    # 검색 결과에서:
    # 1. 파일 경로 → 과목명 + 주차 번호 추출
    # 2. 매칭 라인 위의 가장 가까운 ## 헤더 → 섹션명 추출
    pass
```

### Grep 도구 사용 패턴

문제의 핵심 키워드 2~3개로 Grep 검색을 실행한다:

```
Grep(pattern="키워드", glob="**/강의노트/*.md", output_mode="content", -B=5)
```

검색 결과에서:
- **파일명** (예: `03주차-강의노트.md`) → 주차 추출
- **파일 경로** (예: `.../[4-1] 머신러닝/강의노트/...`) → 과목명 추출
- **매칭 라인 주변의 `##` 헤더** → 섹션(학습단계) 추출

### 출처 출력 예시

```markdown
## 출처

| 과목 | 주차 | 섹션 |
|------|------|------|
| 머신러닝 | 3주차 | 모델 성능 평가 > 교차 검증 |

> 3주차 강의노트 "교차 검증" 섹션에서 K-Fold CV의 원리를 다루고 있습니다.
```

강의노트에서 찾을 수 없는 경우:

```markdown
## 출처

해당 내용은 현재 작성된 강의노트에서 확인되지 않습니다.
미리알림 일정 기준으로 **머신러닝 4주차 (모델 검증 전략)**에서 다룰 가능성이 높습니다.
```

## 5단계: 여러 문제 일괄 처리

사용자가 여러 문제를 한 번에 제공하면:
1. 각 문제를 번호별로 분리
2. 순서대로 하나씩 재정의 + 풀이
3. 마지막에 정답 요약표 제공

### 정답 요약표 예시

```markdown
| 번호 | 정답 | 키워드 | 출처 |
|------|------|--------|------|
| 1 | ③ | 비지도학습 | 머신러닝 12주차 |
| 2 | ① | 정규화 | 빅데이터기초수학 3주차 |
| 3 | O | 과적합 | 머신러닝 3주차 |
```

## 6단계: 코딩 문제 처리

코딩 문제인 경우 추가 처리:
- 코드를 실제로 실행하여 출력 결과 검증
- 오류가 있는 코드면 수정 후 실행
- 풀이 코드를 제공하고 각 줄에 대한 설명 추가

```python
# 코딩 문제는 Bash 도구로 실제 실행하여 결과 검증
# python3 -c "실행할 코드"
```

## 전체 워크플로우

```
1. 입력 판별 (텍스트 vs 이미지)
2. 이미지면 Read 도구로 시각적 인식
3. 문제 유형 판별 (객관식/O·X/단답형/서술형/코딩)
4. 문제 재정의 (정형화된 포맷으로 재구성)
5. 정답 도출 (강의노트 참조 가능)
6. 해설 작성 (정답 이유 + 오답 분석 + 개념 요약)
7. 코딩 문제면 실제 실행으로 검증
```

## 주의사항

- 이미지가 불명확하면 사용자에게 다시 요청
- 문제의 출처나 저작권 관련 내용은 포함하지 않음
- 해설이 확실하지 않은 경우 "불확실" 표시 후 근거 제시
- 수식이 포함된 문제는 LaTeX 코드블록으로 재정의
