# /create-note 커맨드

지정한 과목·주차의 스크립트, 강의교안, 실습 자료를 종합하여 마크다운 강의노트를 작성한다.

## 인자 처리

- `$1` = 과목명 (선택, 없으면 과목 목록에서 선택)
- `$2` = 주차 번호 (선택, 없으면 노트가 없는 주차 목록 제시)

## 전제 조건

- 스크립트/ 폴더에 해당 주차 TXT 파일이 있어야 함
- 스크립트 상단에 학습목록이 정리되어 있으면 더 좋은 결과물이 나옴
- 스크립트가 없으면 사용자에게 먼저 `/transcribe`를 실행하도록 안내

## 실행

1. `create-note` 스킬의 워크플로우를 실행한다
2. 스크립트 TXT + 강의교안 PDF + 실습 PDF를 읽음
3. CLAUDE.md의 서식 규칙에 따라 마크다운 강의노트 작성
4. 강의노트/ 폴더에 `{00주차}-강의노트.md` 형식으로 저장
5. computer:// 링크로 결과물 제공

## 이미 노트가 있는 경우

해당 주차 강의노트가 이미 존재하면 사용자에게 덮어쓸지 확인한다.
